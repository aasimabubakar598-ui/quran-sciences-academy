# Quran Sciences Academy

Bilingual Arabic/English educational website for Quran and Quranic sciences.

## Local preview
Open `public/index.html` in a browser.

## Cloudflare
This repository is configured for Cloudflare Workers Static Assets.
The static site files are in `public/`; Wrangler configuration is in `wrangler.jsonc`.

The first version is a public-facing landing page only. Authentication, private course access,
payments, teacher/student dashboards, and the PDF library must be implemented and secured
before accepting students or payments.
